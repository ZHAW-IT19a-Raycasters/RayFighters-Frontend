raycaster-game

RayFighers Web Client

The web based game client for the Raycaster FPS with Dedicated Multiplayer!

Quickstart Development

Make sure you have Node and NPM installed.

  1. Install dependencies: npm install
  2. start dev server: npm run server

The dev server will now serve the landing page. To join a game a local server instance must be running. Instructions
